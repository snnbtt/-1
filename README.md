1. Цель работы
Цель лабораторной работы — изучить основы объектно-ориентированного программирования на языке Java: создание классов, проектирование конструкторов с перегрузкой и делегированием, организация взаимодействия между объектами, переопределение метода toString(), перегрузка методов, работа со ссылками и графами объектов.

2. Постановка задачи
В соответствии с вариантом 3 необходимо выполнить следующие задания:

Задание 1.3 — Имена. Создать класс Name для хранения ФИО. Имя приводится к строке в формате «Фамилия Имя Отчество», незаполненные поля (null) не выводятся.
Задание 2.2 — Человек с именем. Создать класс Person, использующий объект Name для хранения имени, и поле роста. Вывод в формате «Имя, рост».
Задание 2.3 — Человек с родителем. Добавить поле «Отец» (объект Person). При отсутствии фамилии — наследовать от отца, при отсутствии отчества — образовать от имени отца.
Задание 3.3 — Города. Создать класс City с набором путей к другим городам (город + стоимость). Реализовать граф из 6 городов.
Задание 4.5 — Создаём имена. Реализовать три конструктора класса Name: только имя; имя + фамилия; все три параметра.
Задание 4.6 — Создаём человека. Реализовать четыре конструктора класса Person: имя-строка + рост; имя-строка + рост + отец; имя-объект + рост; имя-объект + рост + отец. Все присваивания только в главном конструкторе.
Задание 5.2 — Кот мяукает. Создать класс Cat с методом meow() и перегруженным методом meow(int n).
5. Описание работы программы и алгоритмы решения
Задание 1.3 — Имена
Алгоритм решения:

Создать класс Name с тремя приватными полями: фамилия, имя, отчество.
Написать три конструктора: только имя; фамилия + имя; фамилия + имя + отчество. Все они вызывают главный конструктор через this(...).
Переопределить toString(): с помощью StringBuilder собрать строку, добавляя только те поля, которые не равны null.
Создать три объекта: new Name("Клеопатра"), new Name("Пушкин", "Александр", "Сергеевич"), new Name("Маяковский", "Владимир").
Вывести через System.out.println().
Пояснение: Три конструктора реализуют перегрузку. Все они делегируют вызов главному конструктору с тремя параметрами через this(...). Вызов this(...) должен быть первой инструкцией в конструкторе. Метод toString() собирает строку через StringBuilder, пропуская поля со значением null, и возвращает результат через trim() для удаления лишних пробелов.

Задание 2.2 — Человек с именем
Алгоритм решения:

Создать класс Person с полями Name name и int height.
Написать конструктор Person(Name name, int height).
Переопределить toString(): вернуть name + ", " + height — автоматически вызывается toString() у объекта Name.
Создать три объекта Person, передав готовые объекты Name и рост.
Вывести через System.out.println().
Пояснение: Поле name имеет тип Name (объект), а не String. При выводе через name + ", " + height автоматически вызывается toString() у объекта Name, поэтому выводится полное имя, а не хэш объекта. Это работает, потому что мы переопределили toString() в классе Name.

Задание 2.3 — Человек с родителем
Алгоритм решения:

Добавить в класс Person поле Person parent.
Написать конструктор Person(Person parent, String name, int height) — принимает отца, строку-имя и рост.
Внутри конструктора создать объект Name из строки с помощью new Name(name).
Проверить: если фамилия не задана (null) и у отца есть фамилия — присвоить фамилию отца через name.setSurname(parent.name.getSurname()).
Проверить: если отчество не задано (null) и у отца есть имя — образовать отчество через метод formPatronymic(parent.name.getName()).
Метод formPatronymic(): если имя оканчивается на «й» — заменить «й» на «евич» (Сергей → Сергеевич), иначе добавить «ович» (Иван → Иванович).
Создать Ивана: new Person(new Name("Чудов", "Иван"), 180).
Создать Петра: new Person(ivan, "Пётр", 175) — от Ивана наследуется фамилия «Чудов» и образуется отчество «Иванович».
Создать Бориса: new Person(pyotr, "Борис", 170) — от Петра наследуется «Чудов» и образуется «Петрович».
Вывести всех троих.
Пояснение: Конструктор с отцом вызывает главный конструктор через this(new Name(name), height, parent). В главном конструкторе проверяется parent != null, и если да — фамилия наследуется от отца, а отчество образуется от имени отца. Метод formPatronymic() — статический, обрабатывает окончание «й» (заменяется на «евич») и все остальные случаи (добавляется «ович»).

Задание 3.3 — Города
Алгоритм решения:

Создать класс City с полями String name и Map<City, Integer> paths.
Использовать LinkedHashMap для сохранения порядка добавления путей.
Написать конструктор City(String name), инициализирующий пустую карту.
Написать метод addPath(City city, int cost) — добавляет запись в карту.
Переопределить toString(): вывести название города, затем в квадратных скобках список путей в формате «город:стоимость» через запятую.
Создать шесть городов: A, B, C, D, E, F.
Добавить связи: a→b(5), a→f(1), a→d(6), f→b(1), f→e(2), e→d(2), d→c(4), c→b(3).
Вывести все шесть городов.
Пояснение: LinkedHashMap выбран вместо HashMap, потому что он сохраняет порядок добавления элементов. Это важно для корректного вывода путей в том порядке, в котором они были заданы. Каждый город хранит карту связанных городов и их стоимости. Метод toString() проходит по записям карты и формирует строку вида «A: [B:5, F:1, D:6]».

Задание 4.5 — Создаём имена
Алгоритм решения:

Класс Name уже имеет три перегруженных конструктора из задания 1.3: Name(String name), Name(String surname, String name), Name(String surname, String name, String patronymic).
Создать первое имя: new Name("Клеопатра") — только личное имя.
Создать второе имя: new Name(null, "Александр", "Сергеевич") — фамилия не задана, только имя и отчество.
Создать третье имя: new Name("Пушкин", "Владимир") — фамилия и имя, отчество не задано.
Создать четвёртое имя: new Name("Маяковский", "Христофор", "Бонифатьевич") — все три параметра.
Вывести все четыре. Метод toString() пропускает поля со значением null.
Пояснение: при создании имени «Александр Сергеевич» фамилия не указана (null), поэтому в выводе она отсутствует — выводится «Александр Сергеевич». Для имени «Пушкин Владимир» не задано отчество — оно также пропускается, выводится «Пушкин Владимир». Это демонстрирует перегрузку конструкторов — три разных способа создать объект одного класса.

Задание 4.6 — Создаём Человека
Алгоритм решения:

Написать главный конструктор Person(Name name, int height, Person parent) — единственное место, где выполняются присвоения полей.
Написать три дополнительных конструктора, каждый вызывает главный через this(...):
Person(String name, int height) → this(new Name(name), height, null)
Person(String name, int height, Person parent) → this(new Name(name), height, parent)
Person(Name name, int height) → this(name, height, null)
В главном конструкторе, если parent != null:
Если фамилия не задана и у отца есть фамилия — наследовать фамилию отца.
Если отчество не задано и у отца есть имя — образовать отчество через formPatronymic().
Создать Льва: new Person("Лев", 170) — только имя и рост.
Создать Сергея: new Person(new Name("Пушкин", "Сергей"), 168, lev) — фамилия задана, отчество образуется от «Лев» → «Львович».
Создать Александра: new Person("Александр", 167, sergey) — фамилия наследуется «Пушкин», отчество от «Сергей» → «Сергеевич».
Вывести всех троих.
Пояснение: Все присвоения полей (this.name = ..., this.height = ..., this.parent = ...) выполняются только в главном конструкторе с тремя параметрами. Остальные конструкторы лишь преобразуют аргументы и делегируют к нему через this(...). Это avoids дублирование кода. При наличии отца фамилия наследуется, а отчество образуется: «Лев» не оканчивается на «й», поэтому добавляется «ович» → «Львович». «Сергей» оканчивается на «й», поэтому «й» заменяется на «евич» → «Сергеевич».

Задание 5.2 — Кот мяукает
Алгоритм решения:

Создать класс Cat с приватным полем String name.
Написать конструктор Cat(String name).
Переопределить toString(): вернуть "кот: " + name.
Написать метод meow(): вывести name + ": мяу!".
Написать перегруженный метод meow(int n): с помощью StringBuilder собрать n «мяу», разделённых дефисом, добавить «!» в конце.
Создать кота: new Cat("Барсик").
Вывести кота через System.out.println(cat).
Вызвать cat.meow() и cat.meow(3).
Пояснение: Метод meow() без параметров выводит одно «мяу!». Перегруженный meow(int n) собирает n «мяу» через StringBuilder, разделяя их дефисом: «мяу-мяу-мяу!». Это демонстрирует перегрузку методов — два метода с одинаковым именем, но разными параметрами. Компилятор выбирает нужный метод по типу и количеству аргументов.
