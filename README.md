Задание 1
Задача 1

Текст задачи

Дана сигнатура метода: public double fraction(double x); Необходимо реализовать метод таким образом, чтобы он возвращал только дробную часть числа x.

Алгоритм решения

Вещественное число преобразуем к целому типу, чтобы отбросить дробную часть. Затем из исходного числа вычитаем полученное целое число.

Задача 3

Текст задачи

Дана сигнатура метода: public int charToNum(char x); Метод принимает символ x, который представляет собой одну из цифр от 0 до 9. Необходимо преобразовать символ в соответствующее число.

Алгоритм решения

Из кода символа x вычитаем код символа '0'. Получаем числовое значение цифры.

Задача 5

Текст задачи

Дана сигнатура метода: public boolean is2Digits(int x); Необходимо реализовать метод таким образом, чтобы он возвращал true, если число x является двузначным.

Алгоритм решения

Проверяем, находится ли число в диапазоне от 10 до 99 или от -99 до -10. Если условие выполняется, возвращаем true, иначе false.

Задача 7

Текст задачи

Дана сигнатура метода: public boolean isInRange(int a, int b, int num); Метод принимает левую и правую границу диапазона a и b и число num. Необходимо вернуть true, если num входит в диапазон, включая границы. Заранее неизвестно, какая из границ больше.

Алгоритм решения

Сравниваем a и b. Если a больше b, меняем их местами. После этого проверяем, что num больше либо равен a и меньше либо равен b.

Задача 9

Текст задачи

Дана сигнатура метода: public boolean isEqual(int a, int b, int c); Необходимо вернуть true, если все три полученных числа равны.

Алгоритм решения

Сравниваем a с b и b с c. Если оба сравнения дают true, возвращаем true, иначе false.

Задание 2

Задача 1

Текст задачи

Дана сигнатура метода: public int abs(int x); Необходимо реализовать метод таким образом, чтобы он возвращал модуль числа x.

Алгоритм решения

Проверяем, является ли x отрицательным. Если да, меняем знак числа на противоположный. Если число неотрицательное, возвращаем его без изменений.

Задача 3

Текст задачи

Дана сигнатура метода: public boolean is35(int x); Метод должен возвращать true, если число x делится нацело на 3 или 5. Если число делится одновременно и на 3, и на 5, необходимо вернуть false.

Алгоритм решения

Сначала проверяем делимость числа одновременно на 3 и 5. Если это так, возвращаем false. В остальных случаях проверяем делимость на 3 или на 5.

Задача 5

Текст задачи

Дана сигнатура метода: public int max3(int x, int y, int z); Необходимо вернуть максимальное из трех полученных чисел.

Алгоритм решения

Сначала считаем максимальным число x. Затем сравниваем его с y и при необходимости заменяем максимальное значение. После этого сравниваем результат с z и возвращаем найденный максимум.

Задача 7

Текст задачи

Дана сигнатура метода: public int sum2(int x, int y); Необходимо вернуть сумму чисел x и y. Если сумма находится в диапазоне от 10 до 19 включительно, необходимо вернуть число 20.

Алгоритм решения

Складываем x и y. Если полученная сумма находится от 10 до 19, возвращаем 20. В противном случае возвращаем обычную сумму.

Задача 9

Текст задачи

Дана сигнатура метода: public String day(int x); Метод принимает число x, обозначающее день недели: 1 — понедельник, 7 — воскресенье. Если число не от 1 до 7, вернуть текст «это не день недели». Вместо if необходимо использовать switch.

Алгоритм решения

Используем конструкцию switch. Для каждого числа от 1 до 7 возвращаем название соответствующего дня недели. В default возвращаем сообщение о том, что это не день недели.

Задание 3

Задача 1

Текст задачи

Дана сигнатура метода: public String listNums(int x); Необходимо вернуть строку, в которой записаны все числа от 0 до x включительно.

Алгоритм решения

Создаем пустую строку. С помощью цикла for перебираем числа от 0 до x и добавляем каждое число в строку.

Задача 3

Текст задачи

Дана сигнатура метода: public String chet(int x); Необходимо вернуть строку, в которой записаны все четные числа от 0 до x включительно. Для решения не следует использовать if.

Алгоритм решения

Создаем цикл for, который начинается с 0 и после каждой итерации увеличивает значение сразу на 2. Таким образом, в строку попадают только четные числа.

Задача 5

Текст задачи

Дана сигнатура метода: public int numLen(long x); Необходимо вернуть количество знаков в числе x.

Алгоритм решения

Берем модуль числа. Пока число больше 0, делим его на 10 и увеличиваем счетчик на 1. Для числа 0 отдельно возвращаем 1.

Задача 7

Текст задачи

Дана сигнатура метода: public void square(int x); Необходимо вывести на экран квадрат из символов * размером x: x символов в каждом ряду и x рядов по высоте.

Алгоритм решения

Используем два вложенных цикла for. Внешний цикл отвечает за количество строк, внутренний — за количество звездочек в каждой строке. После каждой строки выполняем переход на новую строку.

Задача 9

Текст задачи

Дана сигнатура метода: public void rightTriangle(int x); Необходимо вывести треугольник из символов * высотой x, количество звездочек в строке должно совпадать с номером строки. Треугольник должен быть выровнен по правому краю.

Алгоритм решения

Используем два вложенных цикла. Сначала выводим нужное количество пробелов, затем звездочки. Количество пробелов уменьшается, а количество звездочек увеличивается с каждой строкой.

Задание 4

Задача 1

Текст задачи

Дана сигнатура метода: public int findFirst(int[] arr, int x); Необходимо вернуть индекс первого вхождения числа x в массив arr. Если число отсутствует, вернуть -1.

Алгоритм решения

Проходим массив с начала с помощью цикла for. При первом совпадении элемента с x сразу возвращаем его индекс. Если совпадений нет, возвращаем -1.

Задача 3

Текст задачи

Дана сигнатура метода: public int maxAbs(int[] arr); Необходимо вернуть наибольшее по модулю значение массива arr.

Алгоритм решения

Первый элемент массива принимаем за максимальный. Затем перебираем остальные элементы и сравниваем их модули с модулем текущего максимального значения. Если модуль нового элемента больше, запоминаем этот элемент.

Задача 5

Текст задачи

Дана сигнатура метода: public int[] add(int[] arr, int[] ins, int pos); Необходимо вернуть новый массив, в который в позицию pos вставлены все значения массива ins, а остальные элементы взяты из массива arr.

Алгоритм решения

Создаем новый массив размером arr.length + ins.length. Сначала копируем элементы arr до позиции pos, затем вставляем элементы ins, после чего копируем оставшиеся элементы arr.

Задача 7

Текст задачи

Дана сигнатура метода: public int[] reverseBack(int[] arr); Необходимо вернуть новый массив, в котором значения массива arr записаны задом наперед.

Алгоритм решения

Создаем новый массив такого же размера. Проходим исходный массив и записываем его элементы в новый массив с конца: элемент с индексом 0 становится последним, элемент с индексом 1 — предпоследним и так далее.

Задача 9

Текст задачи

Дана сигнатура метода: public int[] findAll(int[] arr, int x); Необходимо вернуть новый массив, в котором записаны индексы всех вхождений числа x в массив arr.

Алгоритм решения

Сначала проходим массив и считаем количество вхождений x. Создаем новый массив нужного размера. Затем второй раз проходим исходный массив и записываем в новый массив индексы всех найденных элементов.
