Задание 1

Задача 1.3 — Имена

Текст задачи

Создать сущность Имя с параметрами Фамилия, Личное имя и Отчество. Любой параметр может быть не задан. Создать Клеопатру, Александра Сергеевича Пушкина и Владимира Маяковского.

Алгоритм решения

1. Создать класс Name с тремя полями.
2. Сделать конструкторы для разных вариантов задания имени.
3. В toString() выводить только заданные части.
4. Создать три требуемых имени и вывести их.

Задание 2

Задача 2.2 — Человек с именем

Текст задачи

Объединить сущности Человек и Имя так, чтобы имя человека задавалось объектом Name, а не строкой. Создать Клеопатру ростом 152, Пушкина Александра Сергеевича ростом 167 и Маяковского Владимира ростом 189.

Алгоритм решения

1. Создать класс Person с полями Name и рост.
2. Создать конструктор с объектом Name и ростом.
3. В toString() вывести имя и рост.
4. Создать трёх людей и вывести их.

Задача 2.3 — Человек с родителем

Текст задачи

Добавить человеку возможность задавать отца, который тоже является человеком. Если фамилия или отчество отсутствуют, их нужно получить от отца: фамилию — от отца, отчество — имя отца с суффиксом «ович». Создать Чудова Ивана, Чудова Петра и Бориса, связав их как отца и сына.

Алгоритм решения

1. Добавить в Person поле father.
2. Добавить конструктор с отцом.
3. При выводе проверить фамилию и отчество.
4. При необходимости взять фамилию отца и образовать отчество.
5. Создать Ивана, Петра и Бориса и связать их.
6. Вывести людей.

Задание 3

Задача 3.3 — Города

Текст задачи

Создать сущность Город с названием и набором путей к следующим городам. Каждый путь содержит город и стоимость поездки. Реализовать схему городов из рисунка задания и строковое представление города.

Алгоритм решения

1. Создать класс City.
2. Хранить список путей к другим городам.
3. Каждый путь хранит город назначения и стоимость.
4. Создать связи из схемы: A→B(5), A→F(1), A→D(6), F→B(1), F→E(2), B→C(3), C→D(4), E→D(2).
5. Вывести города и их пути.

Задание 4

Задача 4.5 — Создаем Имена

Текст задачи

Изменить сущность Имя. Имя можно создать только с личным именем, с личным именем и фамилией или со всеми тремя параметрами. Создать Клеопатру, Александра Сергеевича Пушкина, Владимира Маяковского и Христофора Бонифатьевича, где Христофор — имя, а Бонифатьевич — фамилия.

Алгоритм решения

1. Использовать перегруженные конструкторы класса Name.
2. Создать четыре имени нужными способами.
3. Вывести их с помощью toString().

Задача 4.6 — Создаем Человека

Текст задачи

Изменить сущность Человек. Реализовать создание человека со строковым именем, с именем и отцом, с объектом Name, а также с объектом Name и отцом. При наличии отца дополнять фамилию и отчество. Создать Льва 170, Сергея Пушкина 168 с отцом Львом и Александра 167 с отцом Сергеем.

Алгоритм решения

1. Сделать несколько конструкторов Person.
2. Все конструкторы передают данные в один основной конструктор.
3. Присвоение полей выполнять в основном конструкторе.
4. При выводе дополнять имя данными отца, если это необходимо.
5. Создать трёх людей из условия и вывести их.

Задание 5

Задача 5.2 — Кот мяукает

Текст задачи

Создать сущность Кот с именем. Кот должен иметь строковое представление «кот: Имя», уметь мяукать один раз и уметь мяукать заданное количество раз. Создать Барсика и заставить его мяукнуть один раз, затем три раза.

Алгоритм решения

1. Создать класс Cat с полем имени.
2. Создать конструктор с именем.
3. Реализовать toString().
4. Реализовать meow() для одного мяуканья.
5. Реализовать meow(int count) для заданного количества мяуканий.
6. Создать Барсика и вызвать оба метода.
